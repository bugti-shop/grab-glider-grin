---
name: Free Timeline and selected navigation
description: Timeline Board is free and default; selected bottom navigation uses a persistent light-red icon pill
type: feature
---
Timeline Board must remain available to free users without a paywall or premium crown. It is the default Today Tasks layout when no saved preference exists, while explicit saved choices remain respected. The active bottom-navigation icon uses a persistent soft red pill, including its pressed state, modeled after WhatsApp's selected-tab treatment.
