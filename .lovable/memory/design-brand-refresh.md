---
name: Flowist red brand system
description: Red #db252d brand color, supplied pen-check logo, transparent placements, white native splash screens
 type: design
---
Use #db252d as Flowist's primary brand color across the app, landing page, buttons, cards, folders, sections, highlights, and native surfaces. Use the supplied red-and-black pen/check logo everywhere. Ordinary logo placements must have a tightly cropped transparent background; Android and iOS splash screens must use #FFFFFF behind an enlarged logo; Android should use the more tightly zoomed treatment. Preserve unrelated semantic colors when they communicate status, priority, sticky-note choice, or named themes.

The Upgrade to Flowist Master Plan paywall artwork must show the current red-and-black pen-check logo wearing the crown, never the old blue-green checklist logo. Keep the logo's original white rounded-square background in this paywall artwork so it looks natural.
